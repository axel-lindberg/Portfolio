Overview

Logging food is tedious. Here you describe a meal in plain language — “two eggs and a slice of toast” — and the system takes care of the rest.

AI Calorie Tracker is a full-stack nutrition tracking system. Instead of searching databases and entering portions by hand, meals are typed or dictated. They are stored in PostgreSQL, and the frontend shows the day's log together with total calories and macros.

Type or talk

Log meals in plain language, typed or dictated by voice.

Grounded data

Nutrition values come from USDA FoodData Central, not model guesses.

Tested core logic

Unit tests cover the core nutrition calculations.

How it works

  1. DescribeThe meal is typed or spoken.
  2. ParseFood items, quantities and units are extracted.
  3. MatchEach item is matched against USDA FoodData Central.
  4. ConvertPortions are converted to grams.
  5. ScaleNutrients are scaled to the portion.

My role

AI parsing & food matching

Used the OpenAI API with Pydantic structured outputs to split free text into food items, quantities and units. USDA search results are pre-filtered with RapidFuzz before an LLM picks the matching food, or rejects them all, so nutrition data stays grounded in a trusted source rather than model guesses.

Nutrition calculation

Weight units are converted directly and volume units through an estimated density, with an LLM estimate as the fallback for anything else. Per-100 g nutrient values are then scaled to the actual portion, and the core logic is covered by unit tests.

Backend & database

Designed a REST API in FastAPI for logging and deleting meals, with endpoints for the day's log and totals, backed by a PostgreSQL database running in Docker.

Frontend

Built a lightweight frontend in vanilla JavaScript and Vite, with voice input through the browser's Web Speech API so meals can be dictated instead of typed.
