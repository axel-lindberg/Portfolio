AI Calorie Tracker is a full-stack nutrition tracking system that removes the tedious part of logging food. Instead of searching databases and entering portions by hand, meals are described in plain language, such as "two eggs and a slice of toast", and the system takes care of the rest.

Each description runs through a five-step pipeline:

  1. Describe Meal typed or spoken
  2. Parse Food items, quantities and units
  3. Match Against USDA FoodData Central
  4. Convert Portions to grams
  5. Scale Nutrients to the portion

Meals are stored in PostgreSQL, and the frontend shows the day's log together with total calories and macros.

My role

AI Parsing & Food Matching

  • Used the OpenAI API with Pydantic structured outputs to split free text into food items, quantities and units
  • Pre-filtered USDA search results with RapidFuzz before an LLM picks the matching food, or rejects them all
  • Kept nutrition data grounded in a trusted source rather than model guesses

Nutrition Calculation

  • Weight units converted directly, volume units through an estimated density
  • Falls back to an LLM estimate for anything else
  • Scales per-100 g nutrient values to the actual portion, with the core logic covered by unit tests

Backend & Database

  • Designed a REST API in FastAPI for logging and deleting meals
  • Endpoints for the day's log and totals
  • Backed by a PostgreSQL database running in Docker

Frontend

  • Lightweight frontend in vanilla JavaScript and Vite
  • Voice input through the browser's Web Speech API, so meals can be dictated instead of typed
