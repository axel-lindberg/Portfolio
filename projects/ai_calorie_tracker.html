Overview

AI Calorie Tracker is a full-stack nutrition tracking system that removes the tedious part of logging food. Instead of searching databases and entering portions by hand, meals are described in plain language, typed or dictated by voice, such as "two eggs and a slice of toast", and the system takes care of the rest.

Each description runs through a pipeline that parses it into individual food items with quantities and units, matches every item against the USDA FoodData Central database, converts the portions to grams and scales the nutrient values accordingly. Meals are stored in PostgreSQL, and the frontend shows the day's log together with total calories and macros.

My role

AI Parsing & Food Matching

Used the OpenAI API with Pydantic structured outputs to split free text into food items with quantities and units. USDA search results are pre-filtered with RapidFuzz before an LLM picks the candidate that is actually the same food, or rejects them all, keeping the nutrition data grounded in a trusted source rather than model guesses.

Nutrition Calculation

Built the gram conversion logic: weight units are converted directly, volume units go through an estimated density, and anything else falls back to an LLM estimate. Per-100 g nutrient values are then scaled to the actual portion, with the core logic covered by unit tests.

Backend & Database

Designed a REST API in FastAPI for logging and deleting meals and retrieving the day's log and totals, backed by a PostgreSQL database running in Docker.

Frontend

Built a lightweight frontend in vanilla JavaScript and Vite, including voice input through the browser's Web Speech API so meals can be dictated instead of typed.
