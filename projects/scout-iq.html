Overview

Every week, millions of FPL managers have to decide who to captain, who to start and who to transfer, mostly based on gut feeling and recent form. Scout-IQ replaces the guesswork with a model.

It predicts expected points for every player for the next five gameweeks, and an AI agent answers questions like “Who should I captain?” using those predictions and the official injury news. You can load your own FPL team and get the best starting XI, captain and transfer suggestions.

Beats the baselines

Tested walk-forward on the full 2025-26 season. 5.9% lower error than the best baseline, and the model's captain picks score about 0.75 more points per gameweek.

No data leakage

52 features built only from earlier matches, with a test that proves a match's own result never leaks into its features.

Rules enforced in code

Team selection and transfers are solved by deterministic code, not the LLM, so FPL rules always hold. The agent only explains the result.

How it works

  1. Collect dataThree past seasons plus the current season from the official FPL API, about 94,000 player-match rows.
  2. Build features52 rolling stats such as form, minutes, xG, xA, price and opponent strength.
  3. PredictLightGBM predicts expected points for every player over the next five gameweeks.
  4. Optimise your teamLoad your FPL team and get the best XI, captain and every legal transfer scored over five gameweeks.
  5. Ask the agentA GPT agent with tool calling answers questions from the predictions and injury news (RAG).

My role

Machine learning & evaluation

Built the data pipeline and the leakage-safe features, trained the LightGBM model and evaluated it walk-forward against baselines, retraining before every gameweek as it would run live. Found and fixed real problems along the way, such as early stopping on the wrong metric and a leak in FPL's own data, and ran an experiment showing that player ownership added nothing to the model.

AI agent & RAG

Built an agent on gpt-4o-mini with tools that fetch predictions, compare players, search official injury news with embeddings and analyse your team. Every claim has to come from a tool result.

Team optimiser

Wrote the logic that picks the best XI and captain and scores every legal transfer over the next five gameweeks in about 0.4 seconds, plus a planner for the next five gameweeks and a fixture-difficulty view built from the model's own xG data.

Backend & frontend

FastAPI backend and a React + TypeScript frontend (Vite, TanStack Query, Tailwind). The TypeScript types are generated from the API schema, and a test fails if they get out of sync.
