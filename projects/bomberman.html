Overview

Bare-metal hardware

Runs on a DE10-Lite FPGA board with a 32-bit RISC-V processor.

C + Assembly

Direct control of memory and peripherals, no operating system.

Fully playable

Responsive real-time gameplay on resource-constrained hardware.

This project is a recreation of the classic Bomberman game developed as part of the IS1500 Computer Organization and Components course. Built for the DE10-Lite FPGA board using a 32-bit RISC-V architecture, it demonstrates low-level programming and computer architecture concepts through a fully playable embedded game.

The project was implemented using a combination of C and RISC-V Assembly, requiring direct interaction with hardware components, memory, and peripherals to create responsive gameplay on resource-constrained hardware.

My role

Low-Level Programming

  • Programmed core game systems in C and Assembly
  • Targeted a 32-bit RISC-V architecture

Game Systems

  • Player movement and bomb placement
  • Explosions and collision detection
  • Game state management

Hardware Integration

  • Interfaced directly with FPGA hardware, memory-mapped I/O and peripherals
  • Delivered responsive real-time gameplay
