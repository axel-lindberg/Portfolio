Bomberman

A Bomberman replica built in C for a DE10-Lite FPGA board, running on RISC-V. It won Best Project in IS1500 Computer Organization and Components at KTH.

Overview

The classic Bomberman, rebuilt from the ground up for an FPGA board — no operating system, just C, RISC-V Assembly and the hardware.

Made for the IS1500 Computer Organization and Components course at KTH. Built for the DE10-Lite board with a 32-bit RISC-V processor, the game interacts directly with memory and peripherals to deliver responsive, real-time gameplay on very constrained hardware.

Hardware

Runs on a DE10-Lite FPGA board with a 32-bit RISC-V processor.

C + Assembly

Direct control of memory and peripherals, no operating system.

Fully playable

Responsive real-time gameplay on resource-constrained hardware.

My role

Low-level programming

Programmed the core game systems in C and Assembly, targeting a 32-bit RISC-V architecture.

Game systems

Implemented player movement, bomb placement, explosions, collision detection and game state management.

Hardware integration

Interfaced directly with the FPGA hardware through memory-mapped I/O and peripherals to deliver responsive, real-time gameplay.
